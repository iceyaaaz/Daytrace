# 日迹 X1 验收记录

版本 `v2.4.0-x1` · 分支 `ui/x1` · 基线 `a9b4e7e`（W1）

## 测试环境与测量

- `npm run build` 通过，`npm test` 30 项通过，`npm run check:contrast` 15 套配色组合通过，最低 4.56:1。
- 浏览器测试使用 Windows Edge 的 375px 手机模拟。登录、退出和记录请求使用虚构邮箱及虚构记录，由测试程序在浏览器中模拟返回。
- 登录首屏 JS 按相同 Vite 版本、同一组测试环境变量构建 W1 和 X1，比较 Vite 报告的 gzip 大小。入口 93.89 → 98.74 kB，Supabase 59.15 kB，PWA 注册脚本无变化，登录首屏增量约 **4.85 kB gzip**。今日页独立的头图脚本在登录时无需加载。
- 桌面帧率以 `requestAnimationFrame` 连续约 4 秒采样，并持续移动模拟指针。252 次回调，间隔 4012ms，平均 **62.56fps**。iPhone 12 同级设备的 50fps 指标仍待真机测量。
- 键盘使用 `visualViewport` 的高度和事件判断遮挡，保持单一页面滚动。桌面模拟把可视高度从 812px 降至 400px，断言邮箱、密码、错误栏和登录按钮都完整处于 400px 内。[模拟图](evidence/x1/login-keyboard-viewport.png)

## 假设、未做及待确认

- 动效生效规则按 v1.5 第 3.1 节执行。「开启」优先生效。「跟随系统」随系统减少动效。
- 当前时段按设备本地时间。对比度沿用 W1 令牌，场景和预览的纹样放在独立区域。
- P1 完成邮箱输入时的瞳孔偏移。今日头图的连点彩蛋和历史、回顾页的 72px 纯色图案未做。
- X1 提供两个调试键和光影时段函数。光影画面、周报分享卡留到 X2。森、霓、星糖、色块的相关内容依赖 W2。
- 第 1 步：在 iPhone 用 Safari 打开预览，在登录页依次点邮箱和密码。确认场景缩小，登录按钮和错误文字可见。横屏再点一次密码，确认输入框可操作。
- 第 2 步：设置 → 外观 → 动效 → 关闭。退出登录后看角色保持静止，聚焦密码时仍能静态遮眼。再试「跟随系统」和 iPhone 的「减少动态效果」。
- 第 3 步：用测试账号在兽主题今日页试第一条记录和累计 120 分钟。反馈机型、iOS 版本和遇到问题的画面。正式验收前需要补记真机键盘结果与帧率。

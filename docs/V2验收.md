# 日迹 UI 第三版 · V2 验收

版本 `2.2.0-v2`，分支 `ui/v2`，基于已通过验收的 V1 `f7f5709`。编号按《日迹 UI 第三版》第 11.3 节。文档没有定义 V-53 至 V-59。

测试使用 Chromium 的 375 × 812 手机视口和虚构日记。构建使用测试用占位地址。浏览器测试用模拟接口，另在本地 PostgreSQL 上执行了原建表脚本和新搜索脚本，验证了真实 SQL 行为及账号间隔离。

## 验收约定和待确认项

- 日均四舍五入到整分钟。零分钟的记录计入记录天数；已有零分钟记录的上周会参与总时长比较。
- 「全部」首次显示最近 12 个月，较早月份保留在图的左侧。周、月的未来日期保留空柱位置，周期选择不能进入未来。
- 已完成 P1 的左滑操作和一句话总结。总结取最高用时分类，遇到同分按板块顺序选一项。P2 的读书、运动标签排行留待后续需求。
- V2 的历史搜索需要在预览所用的 Supabase 项目执行 [search-records.sql](../supabase/search-records.sql)。本地 PostgreSQL 已验证，线上项目是否安装由控制台确认。
- iPhone 的主屏幕安全区、状态栏、实际弹出键盘和毛玻璃效果待真机确认。编辑面板沿用 V1 已有的安全区和键盘处理。
- 等手机复测反馈后再继续下一阶段。主题风格本轮暂缓。

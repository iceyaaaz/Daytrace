# 测试指南

使用自己的测试 Supabase 项目、测试账号和虚构记录。环境准备见[部署与备份](部署与备份.md)。

1. **登录**：用错误密码和正确密码各试一次。刷新、关闭浏览器再重开，检查登录状态。退出后用浏览器后退，确认日记不可见。
2. **录入**：从灵感开始试填，检查保存后收起面板，以及「保存并再记一条」能留在原面板。选择昨天补记一条，核对记录归属，并确认未来日期不可选。
3. **断网与跨设备**：填写一条虚构记录后断网，点击保存，确认提示出现且内容保留。恢复网络后重试，在另一台设备登录同一个测试账号核对。
4. **标签与历史**：在学习技能中点「新建」，创建两个标签并用在一条 30 分钟的记录上。删除其中一个标签选项后，确认历史记录仍显示它。统计中两个标签各计入 30 分钟，板块总时长只增加 30 分钟。再试一次按日期查找、编辑和确认删除。
5. **统计与周报**：切换统计页的四个范围，核对图表和表格；切换周报日期，核对记录天数与上周差值。
6. **安装与导出**：从手机浏览器添加到主屏幕，检查名称和图标。导出 CSV 并核对表头、中文和记录数量。
7. **云端访问规则**：在 Supabase 测试项目核对公开注册已关闭，`records` 和 `tags` 均已开启行级访问保护。

已完成的测试及其结果见[验收记录](../验收记录.md)。

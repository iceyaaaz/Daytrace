# 日迹主题风格 W1 验收

版本 `2.3.0-w1`，分支 `ui/w1`，基于已验收的 V2 `809bb60`。验收用 Chromium 和虚构数据，截图视口为 375 × 812。按 v1.4 第 10.3 节执行。

| 编号 | 结果 | 测试方法与观察 |
| --- | --- | --- |
| W-01 | 通过 | 在空浏览器资料中登录虚构账号，检查首次欢迎页、默认兽主题和按钮配色。 |
| W-02 | 通过 | 点击右箭头、按方向键及滚动轮播，检查纸页、雾蓝及固定深色的墨夜，核对根元素与主题色。 |
| W-03 | 通过 | 在墨夜点「就用这个」，检查进入今日、刷新及关闭页面后重新打开，保留墨夜并跳过欢迎页。 |
| W-04 | 通过 | 清除欢迎页标记后打开欢迎页，点「先用默认的」，进入兽主题今日页。 |
| W-05 | 通过 | 设置进入主题页，核对风格与纯色两组、六张卡片、当前主题的对勾和描边。点击切换即时生效，切换前后同一张卡片宽高一致。 |
| W-06 | 通过 | 兽、纸页、雾蓝逐一切换浅色和深色；兽另验证跟随系统，刷新后偏好保持。 |
| W-07 | 通过 | 检查奶咖、樱雾与墨夜的「明暗」行已禁用并说明仅有的明暗版本。单元测试覆盖每个系统明暗和偏好组合。 |
| W-08 | 通过 | 模拟系统深浅切换，核对兽跟随变化。刷新时观察 HTML 初次设置的主题和明暗；由头部脚本先于应用加载写入。 |
| W-09 | 通过 | 核对主题切换时 `meta theme-color` 等于当前 `--bg`，九个启用版本的柱图填色等于板块令牌。安装清单底色为兽的浅色 `#FBEFD9`。 |
| W-10 | 通过 | 运行 `npm run check:contrast`，十套主题共 15 个明暗版本全部达标。纸页浅色 `--text-3` 从 `#6F7671` 微调到 `#6A716C`，在背景上从约 4.25:1 到 4.56:1。 |
| W-11 | 通过 | 检查颜色、圆角和阴影定义集中于令牌，板块配置引用 `--c-*`，头图填色与描边引用主题变量。 |
| W-12 | 通过 | 单元测试检查主题必填令牌、支持的明暗组合和欢迎页完成标记的保存。 |
| W-13 | 通过 | 对照 V2 截图，纸页保留极简列表、板块方形图标、文字层级及功能。颜色使用 v1.4 纸页定义和对比度微调。 |
| W-14 | 通过 | 对照参考图检查尖耳、圆脸、鼻子与脚印。检查 168px 头图、标题与日期在图案左侧。核对兽主题下历史、回顾、设置、面板和保存提示。 |
| W-15 | 通过 | 检查雾蓝、奶咖、樱雾、墨夜的五种明暗组合，今日页没有头图，颜色按主题令牌生效。 |
| W-16 | 通过 | 全量 JS/CSS gzip 从 164,150 B 增至 171,906 B，增加 7,756 B。六套主题切换实测 32–265ms。纯色主界面不请求兽头图，进入展示兽的页面时按需加载；PWA 首次预缓存也跳过该文件。 |
| W-40 | 通过 | 375px 共 45 张必需截图，另有三张欢迎页和主题页截图。 |
| W-41 | 通过 | 模拟「减少动态效果」，检查颜色过渡时长为零，保留 V2 原有的面板和图表减动画规则。 |
| W-42 | 通过 | 在 375px 九组截图状态及 1100px 桌面宽度检查页面宽度。头图用固定比例的 SVG，轮播与长月份图在各自区域内横滑。 |
| W-43 | 未通过 | 尚缺 iPhone 真机证据。需添加到主屏幕后检查刘海、底部横条、状态栏颜色与键盘。 |
| W-44 | 通过 | 核对小猫和脚印为原创 SVG，字体来自系统，图标沿用 Lucide。README 已注明素材与许可。 |
| W-45 | 通过 | 兽和纸页各测试今日保存提示、历史搜索与编辑预填、删除确认、回顾三种周期和 CSV 下载。数据来自模拟接口。 |
| W-46 | 通过 | 检查 Git 差异，改动范围为主题、前端样式、PWA 主题色、测试与文档。 |
| W-47 | 通过 | `npm run build`、`npm test` 均通过，共 24 项单元测试。 |

## 实施约定与手机复测

- 兽的画面以六套参考图和第 5 节为依据。脚印移到小猫左侧与标题区之间，给日期和记录时长留空间。深色版沿用 v1.4 的颜色映射。
- 已有的手动明暗偏好从 V2 的本机设置迁移。欢迎页首次预览遵循系统明暗。
- 森、霓、星糖、色块已落地配色，开放、完整头图、动效、紧凑头图与空状态插画属于 W2。
- 请在 iPhone 主屏幕版本中切换兽与纸页、浅色与深色，再打开填写面板，确认状态栏、安全区和键盘。手机反馈决定是否进入 W2。
